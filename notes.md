# Global
Сделать сайт. Изначально сайт планируется, как визитка.
По дизайну сайт должен быть оформлен в цветах логотипа компании.
У компании есть как белый, так и черный фон. Это наводит на мысли о двух цветовых
темах для сайта.

1. В компанию обращаются клиенты через whatsapp, почта, звонки.
2. Далее клиент говорит что нужно доставить и куда.
3. Так как у компании нет машин, оператор обращается за ценой аренды авто на биржу ati.su.
4. Оператору нужно узнать цену аренды авто и на основании цены сказать стоимость перевозки.
5. Далее на бирже аренды авто оставляется заявка.
6. Через какое-то время, когда отклики собраны, оператор выбирает подходящую машину (смотрит отзывы).


Что нужно:

Онлайн калькулятор
Формирование заказа

# Notes
В оффисе есть локальный сервер.
Он записан на компанию.
Операционная система - windows

Скорость интернета на сервере:
Download - 48.75 Mbps
Upload - 48.70 Mbps

В оффисе имеется два принтера с поддержкой wifi

Все работники подключаются серверу с компьютера удаленно.


Компания пользуется биржой ati.su для заказа машин
api https://ati.su/developers/
